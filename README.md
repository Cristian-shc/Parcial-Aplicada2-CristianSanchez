 Vice City Motors 🚗

Aplicación móvil realizada con React Native y Expo para consultar vehículos de lujo y realizar compras.

 Funciones
- Registro e inicio de sesión.
- Ver catálogo de vehículos.
- Consultar detalles de cada vehículo.
- Comprar vehículos disponibles.
- Ver mis compras.

 Tecnologías
- React Native
- Expo
- JavaScript
- AsyncStorage
- API REST

## Ejecutar el proyecto

bash
npm install
npx expo start

https://vicecity-motors-api.vercel.app
